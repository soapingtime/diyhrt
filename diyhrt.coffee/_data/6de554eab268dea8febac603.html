// what we measure
  • API — health probe against our backend service.
  • database — singleSELECT 1 ping with latency tracking.
  • anti-bot solver — the service we use to clear cloudflare challenges on vendor APIs that block datacenter IPs.
  • each shop poller — derived from the freshness of the most-recent stock check for that vendor. older than 5 minutes = degraded. older than 15 = down.

probes run every 60 seconds from our own monitor, not external tooling. a probe that times out or gets refused counts as downtime. each bar is the worst state seen in that slice.
