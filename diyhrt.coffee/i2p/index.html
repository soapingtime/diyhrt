// i2p1 eepsite

i2p

diyhrt.coffee is mirrored as an I2P eepsite. same site, same data, reached entirely inside I2P without ever touching the normal internet.

if you already run an I2P router, the address below is all you need.

// how a visit travels
// eepsite address

.i2p address

diyhrtn4ycppxnysaavvchbgpzdohgcv2h47icsnjxh5ifdbnlfa.b32.i2p

only resolves inside I2P — you need a router running locally (see below). pasting it into a normal browser without one will not work.

  • not logged

    visits to the eepsite aren't written to our server logs.

  • nothing from outside

    no avatars, captchas or embeds load from the normal internet, and links stay on i2p.

  • built for this

    i2p is designed for services inside it, not as a way out, so there's no exit node.

  • prefer tor?

    the site is a tor onion service too, see /tor.

// getting started
  1. 1

    install a router

    i2pd (small, C++) from i2pd.website, or the official java router from geti2p.net.
  2. 2

    let it warm up

    a new router needs a few minutes to find peers and build tunnels before addresses resolve.
  3. 3

    set your browser's proxy

    http proxy 127.0.0.1:4444, the default for both routers. use a separate browser or profile so your normal browsing doesn't go through it.
  4. 4

    open the address

    the first load can be slow while tunnels build. it speeds up after that. if it doesn't resolve yet, give it a little longer.
