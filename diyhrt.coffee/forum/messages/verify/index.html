check the encryption code

the code that scrambles your messages is a single file. it isn't bundled, minified or built, so what your browser runs is exactly what's written in the source, character for character.

don't trust this page to check itself

the comparison below is a convenience. if someone had already swapped the code, they could just as easily make this page lie about it. the check that counts is the one you run yourself, from your own terminal.

// run thisthe check that counts
# what this server is handing you right now
curl -s https://forum.diyhrt.coffee/e2ee/e2ee-core.js | sha384sum

# what's published for anyone to read
git clone https://github.com/diyhrt-coffee/e2ee && cd e2ee
sha384sum e2ee-core.js

same digest twice means the code you're running is the code that's public. if they differ, stop using this for anything sensitive and say so loudly, in the shoutbox or anywhere else people will see it.

// check who wrote itsigned commits

every commit is signed with the same key that signs the warrant canary. that key is the only identity on the repo, so the signature is the thing to check rather than any account name.

33AA9E20 C6D5FA57 B056C488 E608EDED D5FB9ECF

curl -s https://diyhrt.coffee/api/v1/canary | jq -r .publicKey | gpg --import
git log --show-signature

github shows these as verified too, which is a quicker look but a weaker claim. that badge is github saying a key matches an account on github. the command above is you checking against the key published on the canary page, which doesn't rely on github being honest or unbreached.
